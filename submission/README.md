and upload the ZIP of a full Git clone, including `.git` history. The source ZIP
provided by GitHub's Download ZIP button does not contain that history.

5–10 page limit excluding references/appendices. Check pagination after editing in Word.

remain available from the attributed dataset source described in the main README.

## Required live demonstration within the five-minute presentation

The slides contain seven main slides and two backup/reference slides. Speaker-note
timings total five minutes; shorten approximately 30 seconds of slide narration to
make room for this required live demonstration, preferably after slide 3:

1. Show the GitHub main page and point out `rasher/`, `scripts/`, `tests/` and `results/`.
2. Open local `docs/api/index.html` in a browser and show one function's documentation.
3. Show `results/TEST_REPORT.md` and the final results summary. Explain that analytical
   tests check the implementation while the held-out results measure prediction quality.

Open these tabs/files before presenting. Rehearse the complete talk with a timer.
The brief requires five minutes plus three minutes of questions and a booked Week 14
appointment. No AI assistance is permitted during the assessed interview.

Know the distinction between precision and recall, explain the constant count baseline,
and be honest about class ambiguity, source versus tray independence, and AI contribution.
